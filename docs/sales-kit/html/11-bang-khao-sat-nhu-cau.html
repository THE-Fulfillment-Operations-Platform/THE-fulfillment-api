K. Đánh giá mức phù hợp (nội bộ — điền sau buổi gặp)

Tiêu chíCách chấmĐiểm (0–2)
Sản xuất theo đơn, gom lô theo NVL2 = đúng mô hình · 1 = một phần · 0 = bán hàng có sẵn
Quy mô ≥ 50 đơn/ngày hoặc kế hoạch tăng rõ2 = ≥ 100 · 1 = 50–100 · 0 = < 50 không tăng
Có seller ngoài, cần cổng seller / tracking2 = nhiều seller · 1 = ít · 0 = không
Nỗi đau cụ thể, có số liệu2 = kể được số · 1 = mơ hồ · 0 = “vẫn ổn”
Người quyết định tham gia khảo sát2 = có · 1 = uỷ quyền rõ · 0 = không
Ngân sách trong khung gói2 = có, phù hợp · 1 = chưa rõ · 0 = ngoài khung
Thời điểm triển khai trong 3 tháng tới2 = có · 1 = 3–6 tháng · 0 = không rõ
Yêu cầu tuỳ biến trong khả năng lõi2 = ≤ 5 ngày công · 1 = 5–20 · 0 = cần xây lại
